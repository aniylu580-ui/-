# 记账软件

自托管的个人记账 Web 应用：导入微信/支付宝账单、自动分类、识别退款/借款当天还/AA 分账等"同笔资金"，并用周/月/自定义时间段报表看清钱花在哪。

> 当前处于**阶段 0：文档初始化**，仓库里还没有应用代码。开发计划见 [docs/ROADMAP.md](docs/ROADMAP.md)。

## 核心功能

- **随手记**：手动记一笔收入/支出/转账，支持自定义类目，每笔交易都有发生时间与记录时间
- **账单导入**：识别微信、支付宝导出的账单文件，自动解析、去重、以 UI 风格展示
- **自动分类**：规则 + AI 三层流水线，拿不准时弹窗请你确认，确认结果记入"记事谱"，越用越准
- **同笔资金识别**：自动提议退款、借款当天还、朋友 AA 分账，确认后按真实消费统计
- **报表**：周报、月报、自定义时间段报表，按类目/账户/趋势分析
- **查找**：按时间、商户、类目、金额、备注搜索

## 运行方式（规划）

- 生产：Docker Compose 一键启动（前端 Nginx + 后端 + PostgreSQL），HTTPS 建议 Caddy

## 隐私与安全

- 数据自托管，账单数据不出自有服务器
- AI 分类可配置关闭；开启时只发送最少必要信息
- 密钥只存环境变量，不提交仓库
- 详细安全基线见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
